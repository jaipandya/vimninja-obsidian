VimNinja's tab is named for what it shows, as a note's tab is: the lesson you're on, Today's review, the note you're
practising, VimNinja settings. In VimNinja's Settings, Vim key bindings are a switch, like the Vim keys under them.
Right-clicking a note and choosing Practise Vim on this note now always takes the whole note (a right-click on a word
selected just that word); with a few words selected, Practise Vim on the selection takes those.
