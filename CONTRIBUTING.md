# Contributing to VimNinja for Obsidian

Thanks for helping make VimNinja better.

## Report a bug or ask for something

- **Bugs:** [open an issue](https://github.com/jaipandya/vimninja-obsidian/issues/new) with your Obsidian version,
  your operating system, what you did, what you expected and what happened. A screenshot helps.
- **Ideas and questions:** an issue here, or [vimninja.com/feedback](https://www.vimninja.com/feedback). We read
  everything.
- **Something about your account or Pro:** [support@vimninja.com](mailto:support@vimninja.com), so your details stay
  out of a public issue.

## Pull requests

This repository holds the built plugin (`main.js`, `manifest.json`, `styles.css`), not its source, so code changes
can't be merged here. Fixes to the README are welcome as pull requests. For anything else, open an issue and we'll
take it from there.

## Releases

Each release is tagged with its version (`1.0.1`, no `v`) and published by the release workflow, which attaches the
three files and a GitHub artifact attestation for each, so you can check they came from this repository.
